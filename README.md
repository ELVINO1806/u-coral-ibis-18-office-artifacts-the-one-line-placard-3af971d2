A one-line museum placard for an ordinary office artifact, written as if it belonged in a gallery.

Entry: "Stapler, c. 2019. Pressed steel, jammed. Ritual binding tool of the Accounts tribe; donor unknown, victim's thumb still attached to file 7B."

Run `python3 main.py` — it writes the entry to `/output/entry.txt`.
